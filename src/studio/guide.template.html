CREATE FOR A LITTLE MOMENT

给会议屏，做点有意思的内容。

把一个好问题、一件作品、一个微小的互动放进走廊。观众可能只停留几秒，也可能伸手点一下。无需做一个完整 App：让它一眼能懂、轻触可玩。

当前功能只保存投稿并提供线上预览，不会自动上公司的会议屏。

01 · 你可以设计哪一块？

只设计下方 602 × 382 CSS 像素。上方的会议状态由会议牌负责，不放进你的文件里，也不要遮住或模仿会议状态。

预览会把作品放进整块 602 × 962 的竖屏会议牌，并加 Pad 外壳。设备竖屏全屏尚未复测，这些是当前暂定设计坐标。

02 · 文件怎么准备？

类型规格展示方式
动态 HTML单个 UTF-8 .html / .htm，≤ 20MB。CSS、JS、字体和素材写在文件内，可用内联 SVG 或 data URL。无需 ZIP。602 × 382 的独立视口；允许简单脚本、CSS 动画、点按切换。
图片PNG / JPG / WebP，≤ 20MB。建议 1204 × 764px（2倍导出）；最长边≤4096px，总像素≤1000万。可完整显示留白，或铺满并裁切。图片本身不增加交互。
视频MP4（H.264）或 WebM（VP8 / VP9），≤ 50MB。建议 1204 × 764px、24–30fps、10–30秒；最长60秒，最大1920×1080、30fps。静音自动循环；轻触暂停／继续。内容无需依赖声音。

如果导出比例不同，可以在投稿时选择“完整显示”或“铺满区域”。HTML 无需放入整个会议牌，只让 html, body 占满自己的内容视口。

03 · 为几秒钟和一根手指设计

  • 一个主要内容，最多一两种操作：点按换一句、翻一张卡、暂停动画。打开后就能看，不要求先操作。
  • 正文建议28–40px，主要标题36–48px；少写字，保持明显对比。不要为了容纳更多内容把字挤小。
  • 可点区域至少44 × 44 CSS px，建议54px以上。按钮间留12px，不依赖 hover、精准拖拽、键盘输入或复杂手势。
  • 轻缓动效优先；避免快速闪烁、持续跑马灯、大量粒子和密集计时器。不用3D引擎或复杂游戏。循环可自然衔接，支持 prefers-reduced-motion 更好。
  • 内容保持在画布内：不出现页面滚动条、弹窗、全屏跳转或外链。不要放真实预约、个人隐私或凭据。

05 · 两种投稿方式

网页投稿 · 即时预览

  1. 使用公司飞书账号进入 会议屏创作室。
  2. 选择文件，填写作品名称，可补充署名、介绍和展示方式。右侧立即试播。
  3. 在 Pad 外壳中切换会议状态，点按作品，并检查有无裁切、字是否过小。
  4. 点击“提交并生成预览链接”。文件保存在服务器；之后可从投稿列表再次打开。
  5. 复制预览链接，分享给已登录的公司同事。也可以单独打开大预览。

修改作品后请作为新稿重新提交。撤回后旧预览链接失效。每个账号每日最多30次投稿，所有作品共享1GB存储空间；额度或空间不足时页面会提示。

邮件投稿 · 管理员收件后整理

常见问题

HTML 里能联网吗？当前预览只支持自包含内容：外部图片、字体、脚本、接口和嵌套网页不会加载。请把素材内联；照片或视频可直接选择对应文件投稿。

登录后没有权限？联系公司飞书管理员确认“CreativeFitting Hub”应用对你可用。投稿区与其他 Hub 页面权限独立。

预览等于真机验收吗？预览模拟尺寸、排版、播放和点按；实际 Acer / Fully 的硬件解码、亮度和观看距离仍需现场验证。
